Good questions — here's the straightforward path for Windows 10 + physical Android device:

  ---
  Development & Testing

  Android Studio is the only tool you need (free, from Google).
  - Includes Kotlin, Jetpack Compose, SDK, debugger, and build tools all in one
  - Works well on Windows 10 — recommended 8GB RAM minimum, 8GB disk space

  Testing on your physical device (best approach, much faster than emulator):
  1. On your Android phone → Settings → About Phone → tap Build Number 7 times → Developer Options unlocked
  2. Settings → Developer Options → enable USB Debugging
  3. Connect phone to laptop via USB
  4. Android Studio auto-detects it — press the green ▶ Run button → app installs directly to your phone in seconds   

  Wireless debugging (Android 11+, no cable needed after first pair):
  - Developer Options → Wireless Debugging → pair once → Android Studio sees it over WiFi

  ---
  Google Play Deployment (hassle-free path)

  1. One-time: Create a https://play.google.com/console — $25 registration fee
  2. In Android Studio: Build → Generate Signed Bundle/APK → choose Android App Bundle (.aab) — Google Play prefers   
  this over APK (smaller download for users)
  3. Android Studio walks you through creating a keystore (your signing key — keep this file safe, you need it for    
  every future update)
  4. Upload the .aab to Google Play Console → Create App
  5. Start with the Internal Testing track — lets you test on your own device via Play Store before going public      
  6. When ready: promote to Production

  Internal Testing → Production promotion takes 1-2 days for first review, faster after that.
